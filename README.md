# Mohamed Kalid Ali — Professional Website

This repository contains the source for [mohamedkalidi.github.io](https://mohamedkalidi.github.io), the professional website of Mohamed Kalid Ali, PhD.

## Focus

The website presents research, publications, professional experience, and analytical work across:

- food security and nutrition
- agricultural economics and agrifood systems
- climate resilience and climate-smart agriculture
- humanitarian and development programme evaluation
- quantitative research and data visualization

## Repository structure

- `index.html` — website content and page structure
- `styles.css` — responsive layout and visual styling
- `images/` — profile and research visualization assets

## Local preview

Run a local web server from the repository directory:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Deployment

GitHub Pages publishes the site from the repository's configured default branch. Updates should be reviewed in a pull request before being merged and published.

## Content maintenance

Publication links should point to the journal or DOI page. Conference materials and professional outputs should only be listed when their titles, dates, roles, and links have been verified.
